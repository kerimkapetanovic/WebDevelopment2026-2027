# Tutorial 7 — JavaScript

**Task:** Create a simple webpage using HTML and JavaScript to complete the following four tasks.

Your webpage must include:

1. Add a name input and two buttons, "Save" and "Load". Use `sessionStorage` to save the entered name and display it when Load is clicked.

2. Add a button that uses "try...catch" to check whether a predefined variable age is at least 18. If the age is below 18, throw an error and display its message. Otherwise, display "Access granted."

3. Given the array `[45, 73, 1, 23, 10, 57]`, add two buttons: one to display numbers greater than 20 using `filter()` and another to sort the numbers in ascending order using `sort()`.

4. Create a form with a username and password. On submission, use `preventDefault()` and display an error if the username is empty or the password has fewer than 6 characters. Otherwise, display a success message.
