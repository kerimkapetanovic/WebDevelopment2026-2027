# Tutorial 3 - HTML Portfolio Website 

**Practical Assignment . HTML Only**

**Task:** Create a personal portfolio website using the HTML elements introduced during the tutorial.

Your website must contain:

1. A header with your name and a short introduction.
2. Navigation links to at least three sections of the page.
3. An About Me section with a short biography.
4. An Education and Skills section using lists.
5. A Projects section containing at least two projects.
6. A Contact section with a working email link.
7. At least one external link that opens in a new tab.
8. At least one relevant image of your choice (e.g., a profile picture, university logo, or project screenshot).
9. Appropriate semantic HTML5 elements.

## Bonus Tasks (Optional)

1. **Clickable Image:** Make an image clickable so that it opens an external website.
2. **FAQ Section:** Use `<details>` and `<summary>` to create an expandable question-and-answer section.
3. **Second Page:** Create an additional HTML page (e.g., `projects.html`) and link to it from your main portfolio.
