# Tutorial 5 — JavaScript Basics and Interactivity

**Task:** Use JavaScript to add interactive features to an existing HTML webpage or create a new one. You may add or modify HTML elements where necessary.

Your webpage must include:

1. Add a button that changes the background color of an HTML element when clicked. Clicking the button again should restore the original color.

2. Create a function that checks whether a number is positive, negative or zero. Display the appropriate message based on the result.

3. Add a heading or parag raph to your webpage and a button that changes its text when clicked.

4. Add an input field and a button. When the button is clicked, display the entered text somewhere on the webpage without reloading it.
