# Tutorial 4 — CSS Styling

**Task:** Apply CSS to your existing HTML website or create new HTML elements where necessary to complete the following tasks.

Your website must include:

1. **Colors and Typography:** Make the header background dark blue and its text white. Set the main heading font size to 36 pixels.

2. **Box Model:** Choose any section of your website and add a solid black border with a thickness of 2 pixels and 20 pixels of inner spacing.

3. **Flexbox:** Arrange at least three elements horizontally using Flexbox, with 20 pixels of space between them.

4. **Positioning:** Add a "Back to Top" link that stays fixed in the bottom-right corner of the screen while scrolling.

5. **Hover Effects:** Make at least one link change to red when hovered over, 
optional(with a smooth color transition.)
